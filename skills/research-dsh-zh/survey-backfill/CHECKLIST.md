# CHECKLIST — 纸质问卷回填

## 开工前（Step 0–1）

- [ ] PDF 已确认是扫描件（`pdftotext` 近乎无字）与页数/旋转（`pdfinfo`）
- [ ] 目标问卷 id、workspace/environment id 已记录
- [ ] API key 文件路径已确认；**key 不会写进任何产物**
- [ ] 与用户确认：**页数 = 受访者数**？每页一份还是多页一份？
- [ ] 与用户确认：数值处置策略（区间取中值？「未知」留空？）
- [ ] 与用户确认：是否允许写入线上（写入前先 pilot）
- [ ] 线上问卷结构已落盘 `survey.json`，已标出 `inputType=number` 的题与所有选项 label
- [ ] 平台提交/回读/删除接口与分页参数已验证（`list` 能跑通）

## 识别（Step 2–4）

- [ ] 页图与裁剪图已生成（`assets/render_pages.sh`）
- [ ] 视觉模型已确认**支持图像**（必要时 workflow 覆盖 provider/model）
- [ ] 初读结果已**立即落盘**（防止 workflow 返回值被截断）
- [ ] 覆盖检查：页数 == 已转写页数；缺页只补跑缺失部分
- [ ] 不确定字段已用裁剪图复核（第二轮）
- [ ] 数字/选项/姓名的冲突已仲裁（第三轮），合并优先级 仲裁>复核>初读
- [ ] 空白页/仅签名页已识别并决定是否提交（缺省提交，报告标注）

## 提交（Step 5–7）

- [ ] 数字题全部为纯数字；区间/汉字值的处置逐条进了审计表
- [ ] 选择题存的是**选项 label 文字**；多选/自定义原文存入「其他」
- [ ] 单条 pilot 已提交并回读，字段数与取值正确
- [ ] pilot 测试答卷**已删除**
- [ ] 全量提交完成，失败条目已记录并重试
- [ ] 回读分页拉全量：`提交条数 == 页数`（或差异有据）
- [ ] 每题已答数与预期一致（`verify --summary`）

## 结果页一致性（Step 8）

- [ ] live 问卷题库 ↔ 结果页题卡逐题对齐（覆盖 + 题序）——**spec 缺题会静默少卡**
- [ ] 修改 spec/模板前已备份；改后重跑生成脚本
- [ ] 页面回读：题数、每题已答数、选择题分桶、均值/总和与 API 数据自洽
- [ ] 其他同类结果页（同仓库其他问卷）也做了同样核查

## 交付（Step 9）

- [ ] `BACKFILL_REPORT.md`：受访者清单、识别轮次、转换审计、低置信字段表、核对证据、遗留问题
- [ ] 低置信字段已显式提示用户人工复核
- [ ] 中间产物（页图/裁剪图/转写 JSON/载荷/回读）已保留可追溯
