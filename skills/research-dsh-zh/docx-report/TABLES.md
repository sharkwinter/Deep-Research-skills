## 二、每张表的列规范

1. **口径列不可省**：任何跨来源汇总表必须有一列写明口径（本地装机／在用／自报 `P@FP16`／稠密折算／卡时年），否则读者无法判断能否相加。
2. **样本量写在表内或表下**：问卷类表必须写 `n`，并注明该表以哪个基数为分母（具名主体／有效样本／完整提交）。
3. **单位写进表头**，不写进单元格（`2026年AI需求（A100等效卡时/年）`，而不是每格重复单位）。
4. **`≈` 与 `【推算】` 的含义要在表下统一声明**：`≈` 为折算值，`【推算】` 必须能在正文找到公式与入参（R6.1）。
5. **来源列不能替代角标**：来源/备注列可以有，但**角标必须落在数值所在单元格**（见 §三）。

## 三、引用落位（R10-1，项目实测改进前只有 34%）

- 角标贴**数值**，不贴行：落在该数值所在的单元格之内；同格多源写 `[[a,b]]`。
- **两步工序**（不要手改）：
  1. `assets/add_table_citations.py` —— 按"(文件, 表头行号) → 各行引用"规则把 `[[n]]` 挂到行尾；
  2. `assets/move_citations_to_value.py` —— 把行尾角标搬到**每个数值单元格**内；`--strict` 用于验收。
- **每个数值格都要自带角标**：检查按**单元格**计数，只落在该行第一个数值格会被判未达标；同源多列重复同一角标是**允许且预期**的。
- 验收目标：`R10 数值单元格自带角标 = 100%`（本项目实测 364/364（简）／363/363（繁））。
- **正则必须只有一份**：检查脚本与 `move_citations_to_value.py` 的 `MET` 必须完全一致，否则"100%"不可复现。
- ⚠️ **校验器一律跳过首行**（`rows[1:]` 当作表头）。因此无表头的表格（如卡片带）**必须把首行做成标题行**，否则第一行数据落在校验盲区（R21-4）。

## 四、版式约定

| 项 | `research` 档 | `gov` 档 |
|---|---|---|
| 表内字号 | 9.5pt | 11pt（**有意偏离**：参照件无宽表，7 列对标表在 14pt 下会溢出） |
| 角标字号 | 表内字号 − 1.5pt | 同 |
| 表头 | 首行底纹 `DCE6F1`（`Table Grid`） | 同 |
| 卡片带底纹 | 卡片格 `F4F7FB`、标题行 `DCE6F1`、边框 `BFBFBF`（sz=4） | 同 |
| 栏宽 | 卡片带**固定栏宽**（`tblLayout=fixed` + `tcW`），否则 Word 按内容自动分配、两列错位 | 同 |
| 行距 | 单元格段落 `line=1.05`；**附录区内**改为单倍并关网格吸附（R15-2） | 同，另需 `snapToGrid=0`，否则被 `docGrid linePitch=360` 吸附回去 |

**OOXML 合法性**（不合法时 Word 可能报"文档已损坏"或静默错版）：
- `pPr` 子元素次序固定 → 验收 `pPr 乱序段落数 = 0`；
- `rPr` 子元素次序固定 → 验收 `rPr 乱序 run 数 = 0`（角标超链接须为 `rFonts→color→sz→vertAlign`，本项目实测曾产生 **2,790 处**非法）。

## 五、卡片带（`:cards`）的表格化约定

底稿语法与字段定义见 `SKILL.md` R21。表格结构固定为：

```
第 0 行（合并 colspan=N）：标题（底纹 DCE6F1）＋ 口径/导出时点
第 1..R 行（N 列卡片）：每格 = [图形] 数字[[n]] /  口径说明
末  行（合并 colspan=N）：口径脚注（无边框，小一号灰字）
```

- 每张卡**三件齐**：数字 + 口径说明 + `[[n]]`；数字是真文本（**不得烧进图片**）。
- 图形两选一：栅格化 PNG 图标（标量）或 mini 图表（`donut:`／`hbar:`／`col:`，构成与分布）。
- 卡片带**不引入新参考文献**，不进导航窗格（`outlineLvl` 分布不变）。

## 六、真实踩过的表格缺陷

| 现象 | 根因 | 规避 |
|---|---|---|
| 表格数据没有来源 | 转换器 `allow_cite=False`，且底稿未在格内写 `[[n]]` | 转换器改 `allow_cite=True, cite_size=表内字号−1.5`；两步工序挂角标 |
| 角标挂在行末来源列 | 批量脚本统一追加到最后一格 | `move_citations_to_value.py` 落位到数值格（§三） |
| 替换表格块后**表头行重复** | 替换块自带表头，而原表头仍在 | 替换后把 `\| … \|\n\|---\|\n\| … \|\n\|---\|` 的**重复表头模式收敛为一次** |
| 检查报"未达标"但角标其实在同一行 | 检查按单元格计数，而角标只落在该行第一个数值格 | 逐值规则下每个数值格都要自带角标 |
| 形如 `82.5万A100等效卡时/年` 的数值漏检 | `MET` 只认"数字紧跟单位"，未覆盖"数量+型号+等效+单位" | `MET` 增加 `等效` 分支；**检查脚本与移动脚本共用同一份正则** |
| 合计与分项对不上 | 汇总表取了不同基数（如把"46 家有效样本"写成"46 家完整提交"） | 三基数分列（R20-2）；每张汇总表注明分母 |
| 卡片带第一行逃过校验 | 校验器 `rows[1:]` | 首行做成标题行（R21-4） |
