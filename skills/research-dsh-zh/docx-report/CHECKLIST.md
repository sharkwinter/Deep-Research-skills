# CHECKLIST.md — 交付前逐项验收

> 全部条目必须通过；R2（无自动编号）与 R3（角标可跳转）是**一票否决项**。

## A. 结构（模板保真）
- [ ] 章节结构与模板**逐节对应**，无缺章、无改序、无自创章节
- [ ] 页面为模板尺寸与页边距（A4 11905×16840；上下 1440 / 左右 1800 twips）
- [ ] 正文/标题字体一致（如 等线 / Arial），字号与模板基线一致
- [ ] 目录存在且层级正确；页脚有页码

## B. 编号（R2，一票否决）
- [ ] 转换后 `styles == {'Normal'}`（无 `List Number` / `List Bullet`）
- [ ] `document.xml` 中 `<w:numPr>` 出现次数 = **0**
- [ ] `ListNumber|ListBullet` 引用次数 = **0**
- [ ] 抽查 3 处有序列表，确认**每个列表从 1 重新计数**，且不跨标题续号

## C. 引用角标（R3 / R5）
- [ ] 角标为**上标**：`w:vertAlign w:val="superscript"` 数量 = 角标数
- [ ] 角标为**内部超链接**：`<w:hyperlink w:anchor="_RefN">` 数量 = 角标数
- [ ] **多编号引用逐编号成链**：`[1,2,5]` 对应 **3 条** hyperlink（`_Ref1`/`_Ref2`/`_Ref5`），不是 1 条
- [ ] 全文**链接总数 ≈ 各引用编号个数之和**（远大于角标段落数）
- [ ] 参考文献条目均有书签 `_RefN`，且书签 id 全文档唯一
- [ ] **`unresolved anchors == []`**（零失效链接）
- [ ] 关键判断段落（含 结论/判断/建议/定位/总体架构 等）引用覆盖率 = **100%**
- [ ] 抽查 Word 中点击 5 个角标（含 1 个多编号角标的第 2、3 个数字），均跳到正确条目

## C1. 表格数据引用（R5 表格部分）
- [ ] 转换器对表格开启引用解析（`add_table(..., allow_cite=True, cite_size=8.0)`）
- [ ] **关键数据速览表逐行有角标**，落在"口径与来源"等最后一列
- [ ] 统计表 / 对标表 / 判给台账 / 预测表：能定位到源的数据行均挂角标
- [ ] 含引用链接的表格单元格数 > 0（自检脚本输出 `cells with citation`）
- [ ] 关键数据速览表下有**表注**，说明上标数字可点击跳转至附录F
- [ ] 表格角标为 8pt 上标，不影响单元格行高与排版

## C2. 导航窗格标题树
- [ ] 章/节/子节均带 `outlineLvl`（1/2/3），层级正确
- [ ] **附录内的分组标签（如「【一】…」）是 `####` 标题**，`outlineLvl=3`，在 Word 导航窗格中显示为附录的子级
- [ ] 分组标签为标题而非加粗正文；标题文字完整（首尾括号未被正则吞掉）

## C4. 算力指标逐值精确引用（R10）
- [ ] 每个算力指标数值（PFLOPS/P@FP16/Eops/EFLOPS/A100 等效/卡时/卡数/利用率/元每卡时）**角标紧贴数值**
- [ ] 表格中角标落在**数值所在单元格**，不是整行的"来源/备注"列
- [ ] 自检脚本输出"数值单元格自带角标率" = **100%**（旧版实测仅 34%）
- [ ] 政府/法规/判给类条目含**文号或批准文件号 + 日期 + 具体定位**
- [ ] 网页类条目含 **URL + 抓取日期**
- [ ] 财报类条目含**报告期 + 页码/章节**
- [ ] 一手调研类条目含**记录级定位**（记录号/企业名/题号），如"问卷 q4 记录 #19"
- [ ] `【推算】` 的算力指标已**逐入参引用来源**，未只引"本报告推算"
- [ ] 无"用调研报告整体条目支撑具体算力数字"的组引用兜底
- [ ] 口径不一的算力值（如 4 Eops / 1.16 EFLOPS）**各自有角标并注明口径**

## D. 参考文献（R4）
- [ ] 每条含：机构/作者 + 文件名/标题 + 文号或日期 +（如有）URL 或落盘路径
- [ ] 按主题分组编号，编号连续无跳号、无重复
- [ ] 正文引用编号均在参考文献编号范围内（无悬空引用）
- [ ] **无"僵尸文献"**：1..N 每个编号都至少在正文或表格中被引用一次（差集为空）
- [ ] 附注说明了原始资料（网页/PDF/逐字摘录）的落盘位置

## E. 内容与证据（R6 分级 / R7）
- [ ] 用户点名的参考资料**全部被使用**并在参考文献中登记
- [ ] 每个量化陈述带单位与口径（年份/口径/来源）
- [ ] 口径矛盾**并录**并注明差异，未静默择一
- [ ] 未取得项明确写为"未公开 / 未取得（负面发现）"，**无编造**
- [ ] 正文为简体中文；公司/机构名保留登记原文

## E1. 数据可信度与可追溯（R6.1–R6.4 / R8）
- [ ] 每处 `【推算】` 都在正文给出**公式**（不是只把公式留在底稿/子代理报告里）
- [ ] 每处推算都有**参数取值 + 口径 + 来源角标**
- [ ] 折算系数/专家基准集中列在《调研方法与口径说明》，并注明来源
- [ ] 抽查 **10 个关键数字**，均可在 `sources/`、判给台账或问卷中定位到原始出处
- [ ] 推算值均在**量级上下限**内；越界已解释或拆分为子项
- [ ] 无"把算术和当瞬时负载"；峰值类数字已注明"**非任一时点负载**"并剥离非自有资产
- [ ] 自述能力均有「支持证据 / 不支持证据 / 偏离判定」三栏，**无单独转述自述的结论句**
- [ ] 每条建议均回指其问题章节，并给出**量化代价**（非形容词）
- [ ] 附录存在「短板/问题 → 建议 → 量化代价 → 依据」映射表，逐行有角标
- [ ] 被转换器高亮的证据标记（`【推算】`/`【冲突】`/`【未取得】`）在 Word 中确为浅底纹
