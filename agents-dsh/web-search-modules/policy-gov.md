# Government & Policy Module

> 政府政策、法律法规、官方统计的专用检索策略（政府源优先、PDF 纪律、多语言变体、精确到条文文号）

**触发场景**: 政策法规、政府规划、官方统计、跨境数据规则、立法/质询文件、公用事业与国企披露

## 搜索源（政府与官方，按优先级）
- **澳门特别行政区政府** (gov.mo) — 政府新闻网、施政报告、各司局（经济及科技发展局、公职局、邮电局等）
- **澳门特区政府公报/印务局** (io.gov.mo) — 法律法规原文（第X/XXXX号法律、行政法规）
- **澳门立法会** (al.gov.mo) — 议员书面质询及政府回覆（多为PDF，常含未公开的运营与规划数据）
- **澳门个人资料保护办公室** (gpdp.gov.mo) — 个资法适用指引、个人数据跨境转移规定
- **统计暨普查局 DSEC** (dsec.gov.mo) — 官方统计（经济、行业、能源、信息通讯）
- **横琴粤澳深度合作区** (hengqin.gov.cn) — 合作区政策、数据出境负面清单与落地实践
- **广东省人民政府** (gd.gov.cn) 及省政务服务和数据管理局 — 省级算力/数据要素政策
- **国家层面**：国务院政策文件库、国家数据局、国家发改委（"东数西算"、全国一体化算力网）、工信部
- **公用事业/企业披露**：澳门电讯 CTM、澳门电力 CEM（年报、新闻稿、资费页）、华为数字能源白皮书
- **智库二手源**（须回源或标注口径）：国家信息中心、中国信通院白皮书、IDC — 引用其数字须找到原始出处，否则标注为该机构口径

## 查询策略（多语言变体 + 文号精确检索）
- 澳门官方为**繁体中文 + 葡文 + 英文**三语，同一名词多语检索（如：数据跨境 / transferência de dados / cross-border data transfer）；葡文源有时更早更全，对"国际化"主题有独特价值；检索澳门本地内容用**繁体**关键词
- 法律法规用**编号精确检索**（如 "第8/2005号法律"、"8/2005号法律 个人资料保护法"），引用必须精确到条文号
- 政策检索加时间限定词（"2025"、"最新"、"修订"），法规注意生效状态与新旧版本更替
- 质询回覆类PDF：用站点限定（如 `site:al.gov.mo 質詢 算力`）+ 议员名 + 主题词组合

## PDF 纪律
- 澳门公报、立法会回覆、DSEC统计多为 PDF：`curl -L -o` 落盘，校验非零且以 `%PDF` 开头
- 文件名带日期与文号（如 `al_reply_2025-05_算力.pdf`），sources 清单记录文号 + URL + 访问日期

## 引用纪律
- 法条引用精确到：法律/行政法规编号 + 条款号 + 生效/修订日期
- 统计数字标注：机构、口径、统计期（DSEC 数据注明统计年鉴/期号）
- 中葡英版本内容有出入时，以**作准文本**（澳门法律通常以葡文版作准）为准，正文注明所据版本
- 二手报道与官方原文冲突时，以官方原文为准并回源落盘
